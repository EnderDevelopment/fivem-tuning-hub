# FiveM Tuning Hub

FiveM Tuning Hub is an advanced garage and premium tuning system for FiveM servers. It provides a comprehensive solution for managing vehicle garages, tuning shops, and vehicle modifications. The plugin integrates with popular FiveM frameworks and libraries, offering a seamless experience for both server administrators and players.

## Install

1. Download the latest release from the GitHub repository.
2. Extract the contents of the ZIP file into your FiveM server's `resources` directory.
3. Add the following line to your `server.cfg` file:
   ```
   ensure FiveM-Tuning-Hub
   ```
4. Restart your FiveM server.

## Use

1. Configure the `config.lua` file to set up garages, tuning shops, and other settings.
2. Players can access garages by interacting with the garage markers on the map.
3. Players can visit tuning shops to purchase and apply vehicle modifications.
4. Use the `/tuning` command to open the tuning menu and manage vehicle modifications.
